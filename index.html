Classification thresholds

BMI is a rough proxy and doesn't account well for muscle mass in growing athletes. Fat-free mass varies by height/age, so its threshold is optional.

Rounds

Archiving closes the current round under the name you choose, clears check-ins and opens a new round with everyone pending. Previous values stay visible on each player's History.

Import from photo or PDF Arboleaf reports

Reads JPG, PNG, WebP and PDF reports on this device (nothing is uploaded; only the reader code and its language file are downloaded the first time). You review and correct every value before anything is saved.

Import measurements CSV, into any round

Columns: player (name), date (YYYY-MM-DD, optional) and any of body_fat_percent, subcutaneous_fat_percent, total_body_water_percent, bmi, fat_free_mass_kg, visceral_fat, skeletal_muscle_mass_kg, weight_kg and balance_upper / balance_lower / balance_overall (balanced, slight, severe). Commas or semicolons both work. You choose the round and whether to only fill empty values before anything is saved.

Data

The JSON backup has everything (players, bioimpedance, anthropometry, notes, tags, thresholds). Exports download to this device and contain player data: store them somewhere private and never put them in a repository. Check-ins are shared across devices.
